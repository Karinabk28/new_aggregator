# 📰 News Aggregator - Scrapy Project

¡Bienvenido a **News Aggregator**! 🚀  

Este proyecto está desarrollado con **Scrapy** y permite extraer artículos de noticias de tres medios españoles:

- **El País** 📰  
- **La Vanguardia** 🗞️  
- **20 Minutos** 🕒  

El objetivo es **practicar scraping**, manejar múltiples spiders y consolidar toda la información en un único archivo JSON (`datos.json`).

## ⚡ Qué hace

- Extrae artículos de los tres medios mencionados.  
- Obtiene información como **título, fecha, enlace y resumen**.  
- Consolida todos los artículos en un **único archivo JSON** para facilitar análisis posterior.  
- Ignora automáticamente archivos de cache de Python (`__pycache__`) y `.pyc`.
